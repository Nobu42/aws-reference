クラウドセキュリティ対応 パラメータシート変更対象一覧

目的:
今回のクラウドセキュリティ対応で、パラメータシートへ追加、更新、または実環境値との突合が必要になる項目を整理する。

前提:
実際の列名は現場のパラメータシート正式名称に合わせて読み替える。
パラメータシートに該当列がない場合は、新規列追加、備考欄記載、または別紙管理のいずれかを確認する。
A-gate、EventBridge、既存監視で対応済みの要件は、設定値を新規作成しない場合でも「対応区分」「既存設定名」「根拠証跡」を記録する。
