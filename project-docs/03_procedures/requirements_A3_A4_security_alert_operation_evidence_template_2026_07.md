# 要件A3/A4 セキュリティアラート運用証跡テンプレート

作成日: 2026-07-12

この資料は、要件A3/A4で求められるセキュリティアラート運用手順と日々の運用証跡を残すためのテンプレートである。

正式資料では、GuardDutyを用いたセキュリティアラートのモニタリング手順書がないこと、GuardDutyで検知されたイベント調査に関するエビデンスが提出されていないことが指摘されている。

## 1. 証跡管理の目的

- アラート発生日時を残す
- 対応者を残す
- 確認したログと判断根拠を残す
- 誤検知、対応不要、要対応の判断を残す
- エスカレーション有無を残す
- 完了日時を残す
- 月次確認ではなく、即時対応が必要なアラートを追跡できる状態にする

## 8. Archive判断

GuardDuty FindingをArchiveする場合、以下を確認する。

| 確認項目 | 内容 |
| :--- | :--- |
| 原因が特定済み | 既知作業、テスト、仕様、誤検知など |
| 対応不要の根拠がある | 変更管理、関係者確認、ログ確認 |
| 再発時の扱いが明確 | 再通知するか、抑制するか |
| 承認者がいる | 個人判断でArchiveしない |
| 証跡が残っている | Archive理由を後から追える |

Archiveは「削除」ではなく、確認済みとして通常の未対応一覧から除外する運用上の整理である。
