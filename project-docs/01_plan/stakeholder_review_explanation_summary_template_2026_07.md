# レビュー・説明用サマリ テンプレート

作成日: 2026-07-12

この資料は、クラウドセキュリティ対応について、関係者レビューや説明時に使うサマリのテンプレートである。

正式な評価シートに記載された要件、リスク、是正対応案をもとに、実施内容、業務影響、テスト結果、残課題を簡潔に説明する。

## 4. 業務影響サマリ

| 影響候補 | 内容 | 対策 |
| :--- | :--- | :--- |
| ログ量増加 | S3 Server Access Logging、VPC Flow Logs、CloudWatch Logsで保管量が増える | 保存期間、保存先、コストを確認 |
| 通知量増加 | Alarm追加によりメールやTeams通知が増える | 通知先、閾値、テスト日時を確認 |
| 画面確認負荷 | CloudWatch LogsやEventBridge Rule一覧の確認対象が増える | 命名規則と一覧表を整備 |
| KMS権限影響 | CloudTrailログ参照にKMS Decrypt権限が必要になる | Key PolicyとIAM権限を確認 |
| 既存通知重複 | EventBridgeや既存SNSと重複する可能性 | 既存通知経路を確認 |
