CloudWatch Alarm設定手順

対象:
4.1〜4.15

前提:
Metric Filterは作成済みとする。
Metric NamespaceはCustomを使用する。
通知先は既存SNS Topicを使用する。

共通設定値:
Statistic: Sum
Period: 5 minutes
Threshold type: Static
Condition: Greater/Equal
Threshold value: 1
Datapoints to alarm: 1 out of 1
Missing data treatment: Treat missing data as not breaching
Alarm action: In alarm
SNS Topic: 既存SNS Topic
Actions enabled: 有効

作成手順:
1. AWS Management Consoleへログインする。
2. 対象アカウント、対象リージョンを確認する。
3. CloudWatchを開く。
4. 左メニューで「アラーム」を開く。
5. 「すべてのアラーム」を開く。
6. 「アラームの作成」をクリックする。
7. 「メトリクスの選択」をクリックする。
8. 「すべてのメトリクス」からCustomを選択する。
9. 対象要件のMetric Nameを検索する。
10. 対象Metricを選択する。
11. 「メトリクスの選択」をクリックする。
12. StatisticにSumを選択する。
13. Periodに5 minutesを選択する。
14. ConditionsでStaticを選択する。
15. Whenever Metric Name is...でGreater/Equalを選択する。
16. thanに1を入力する。
17. Additional configurationを開く。
18. Datapoints to alarmに1 out of 1を設定する。
19. Missing data treatmentでTreat missing data as not breachingを選択する。
20. 「次へ」をクリックする。
21. NotificationでIn alarmを選択する。
22. Select an SNS topicで既存SNS Topicを選択する。
23. 「次へ」をクリックする。
24. Alarm nameに対象要件のAlarm名を入力する。
25. Alarm descriptionに対象要件番号と監視対象を入力する。
26. 「次へ」をクリックする。
27. PreviewでMetric Name、Statistic、Period、Threshold、SNS Topic、Alarm名を確認する。
28. 「アラームの作成」をクリックする。
29. 作成後、Alarm一覧で対象Alarmを検索する。
30. 対象Alarmを開く。
31. Metric、Condition、Notification、Actions enabledを確認する。
32. 同じ手順を対象要件分繰り返す。
