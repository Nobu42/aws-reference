# 要件別 対応内容 Excel貼り付け用

作成日: 2026-07-08

この資料は、評価シートに列を追加し、各要件番号に対する対応内容を1セルへ記載するための下書きである。

最初に共有された評価シート由来のテキスト情報を正とし、ND記入欄にある「現状整理、設計、手順作成、開発環境設定、テスト」の流れに沿って整理する。
公開リポジトリで扱うことを想定し、顧客名、案件名、会社名、具体的な環境名、AWSアカウントID、S3バケット名、VPC ID、個人名、内部資料の正式名称は記載しない。

## 1. 使い方

1. Excelに `対応内容` などの列を1つ追加する。
2. 下のTSVから、必要な範囲をコピーする。
3. `要件番号` と `対応内容` の2列として貼り付ける。
4. 既存Excelに要件番号列がある場合は、`対応内容` 列だけをコピーして貼り付けてもよい。

## 3. 列名候補

Excelに追加する列名は、以下のいずれかが使いやすい。

| 列名候補 | 向いている場合 |
|---|---|
| 対応内容 | シンプルにしたい場合 |
| 作業内容 | 作業者向けにしたい場合 |
| 具体対応内容 | リーダーやレビュー担当へ説明したい場合 |
| ND対応内容 | 元シートのND記入欄に寄せたい場合 |

## 4. 注意点

- 1セルに入れる前提のため、文章は短めにしている。
- 正式な原本Excelに転記する場合は、最新の要件番号順と照合する。
- 顧客名、案件名、会社名、AWSアカウントID、具体的なリソース名は入れていない。
- EventBridgeは元要件の必須方式ではないため、この対応内容には含めていない。
